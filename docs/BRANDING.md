# Sentiq Brand Guidelines

This document outlines the design tokens, colors, fonts, and usage rules for both Sentiq brands.

## 1. Sentiq.AI
The core product brand—a self-hosted AI workspace.

**Icon Concept:** Connected-nodes S-curve mark
- Represents neural networks, connectivity, and continuous flow.
- Formed by a smooth, overlapping 'S' curve anchoring three primary nodes.

**Colors:**
- Primary Gradient: Electric Blue (`#00F2FE` to `#4FACFE`)
- Text (Light mode): Slate 900 (`#0F172A`)
- Text (Dark mode): Slate 50 (`#F8FAFC`)

## 2. Sentiq Labs
The parent business brand—voice agents and AI automation services.

**Icon Concept:** Paired hexagon + waveform mark
- Hexagon represents structure, stability, and technology.
- Waveform represents voice, dynamic data, and communication.

**Colors:**
- Primary Gradient: Blue/Violet (`#6366F1` to `#8B5CF6`)
- Text (Light mode): Slate 900 (`#0F172A`)
- Text (Dark mode): Slate 50 (`#F8FAFC`)

## Typography
- **Primary Font:** 'Outfit', sans-serif
- **Weight:** 700 (Bold) for wordmarks, tighter letter-spacing (`-2px`) for a compact, modern feel.

## Usage Rules (Both Brands)
1. **Clear Space:** Always maintain a clear space around the logo equal to the width of the main icon's inner node (or 20% of the logo's height).
2. **Minimum Size:**
   - Wordmark lockup: Do not use below 120px in width.
   - Icon-only: Do not use below 16px in width (favicon size).
3. **Contrast:** Ensure sufficient contrast. Always use the Dark variant (white text) on dark backgrounds, and the Light variant (dark text) on light backgrounds.
4. **Distortion:** Do not stretch, skew, or alter the geometry of the logo or its gradients.
